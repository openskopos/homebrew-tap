# OpenSkopos Homebrew tap

This tap installs `skopos`, the command-line tool for
[OpenSkopos](https://openskopos.org) documents.

```bash
brew install openskopos/tap/skopos
```

The release workflow of [openskopos/openskopos](https://github.com/openskopos/openskopos)
writes the formula in `Formula/` on each release. Do not edit it by hand.
